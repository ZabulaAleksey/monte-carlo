# Пульс рынка на Dashboard

## Назначение

Пользователь должен видеть в выборе «Пульса рынка» все доступные валютные пары MT5, для которых получена актуальная котировка, даже если их свечи не вошли в первоначальный общий срез Dashboard.

## Требования

- `MP-001`: список содержит каждую активную валютную пару из каталога инструментов, если для неё доступна котировка текущего источника данных.
- `MP-002`: выбор валютной пары и выбор таймфрейма являются отдельными полями. В selector валютных пар не добавляются металлы, индексы, криптовалюты и другие невалютные инструменты; если FX-данных нет, существующая свечная серия остаётся fallback для обратной совместимости.
- `MP-003`: валютная пара определяется по базовой и котируемой валюте в имени инструмента с поддержкой типичных брокерских префиксов и суффиксов.
- `MP-004`: для пары и таймфрейма без свечей в первоначальном срезе история выбранного `symbol/timeframe` загружается отдельным ограниченным запросом. Поддерживаются `M1`, `M5`, `M15`, `M30`, `H1`, `H4`, `D1`.
- `MP-005`: live-котировки продолжают обновляться каждые 500 мс только пока Dashboard смонтирован; расширение списка не запускает отдельный realtime-запрос на каждую пару.
- `MP-006`: выбранная серия продолжает сохраняться в `localStorage`.
- `MP-007`: Dashboard выбирает счёт, совпадающий с `account_external_id` активного MT5-терминала, и обновляет account/trades не реже одного раза в 2 секунды.
- `MP-008`: реализованный P&L является суммой `profit + commission + swap` закрытых сделок; доля прибыльных считается по положительному net P&L закрытых сделок.
- `MP-009`: пустой MT5 trade batch является валидным состоянием без закрытых сделок и не нарушает цикл синхронизации.
- `MP-010`: терминал считается подключённым при свежем heartbeat или свежей успешной авторизованной синхронизации данных.

## Критерии приёмки

1. При наличии котировок EURUSD, GBPJPY и XAUUSD в selector валютных пар появляются EURUSD и GBPJPY, но не XAUUSD; таймфрейм выбирается отдельным полем.
2. Выбор quote-only пары или нового таймфрейма вызывает один запрос свечей с соответствующими `symbol_id`, `timeframe` и ограничением 500.
3. Повторный render или параллельный запрос не создаёт дублирующую загрузку той же серии.
4. Периодический полный refresh не удаляет уже загруженную выбранную серию.
5. Существующие тесты Dashboard и 500-мс обновления котировок проходят без регрессий.
6. Свежий quote sync не отображается как отключённый терминал при устаревшем heartbeat.
7. Account текущего терминала, net realized P&L и доля прибыльных отображаются после синхронизации; `trades: []` принимается с HTTP 200.

## Non-goals

- Массовая предварительная загрузка истории всех валютных пар.
- Сохранение полного потока тиков.
- Добавление нового asset-class поля в каталог инструментов MT5.
