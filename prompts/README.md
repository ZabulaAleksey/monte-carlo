# Поэтапные launchers

Эти файлы не являются второй копией требований. Каноническое содержание этапов
находится в [дорожной карте](../docs/MONTE_CARLO_ROADMAP_13_TO_28.md).

Перед запуском этапа:

1. прочитай соответствующий раздел дорожной карты;
2. проверь `docs/AI_STATUS.md`, зависимости и технический долг;
3. подготовь ограниченный SPEC/ADR и план проверок;
4. реализуй только явно запрошенный этап;
5. обнови живой контекст и остановись перед следующим этапом.

Этапы 14–28 опциональны; launchers для них создаются только после отдельного
решения пользователя.
