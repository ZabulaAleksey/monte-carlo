# Project instructions

Перед началом работы прочитай `~/codex-workspace/AGENTS.md`. Этот файл содержит
только проектные ограничения и маршрутизацию контекста.

## Источники истины

- Контракт системы: `specs/system.spec.md`.
- Реализованная архитектура: `docs/architecture.md`.
- Каноническая последовательность этапов: `docs/MONTE_CARLO_ROADMAP_13_TO_28.md`.
- Краткий статус и следующий шаг: `docs/AI_STATUS.md` и `docs/AI_PLAN.md`.
- Правила совместимости контекста: `docs/CONTEXT_COMPATIBILITY.md`.

Перед изменением кода прочитай только относящийся к задаче раздел дорожной
карты, соответствующий launcher из `prompts/` и действующие SPEC/ADR. Не считай
планы доказательством реализованного состояния: его подтверждают код и тесты.

## Этапы

- Этапы 1–13 — базовая дорожная карта.
- Этапы 14–28 — опциональные и не начинаются без прямого запроса пользователя.
- Историческое название текущей ветки «Этап 3. Движок стратегий и бэктестинг»
  функционально соответствует преимущественно каноническому этапу 6.
- Перед этапом 7 требуется reconciliation gate из `docs/AI_PLAN.md`.

## Инварианты

- Домен бэктестинга не зависит от FastAPI, SQLAlchemy и MetaTrader.
- Запрещён look-ahead bias; воспроизводимость включает seed, параметры и
  provenance данных.
- `TD-BT-001` блокирует доверие финансовым результатам до golden-data сверки.
- `TD-UI-001` сохраняется как технический долг карты исполнения.
- Не ослабляй read-only границу MT5 и требования точности финансовых данных.
- Считай данные рынка, счетов и сделок чувствительными; не коммить `.env`, ключи
  и реальные учётные данные.

## Проверки

- Frontend: `npm run lint` и `npm test` из `apps/frontend`; при изменении
  сборки также `npm run build`.
- Backend: `python -m pytest`, настроенные Ruff и mypy из `apps/backend`.
- Принятые unit/integration/component тесты считаются контрактными; новые
  сценарии добавляются отдельной задачей, а не подгоняются в цикле верификации.
- Если критический E2E зависит от недоступного MT5 pipeline, зафиксируй
  `BLOCKED_BY_BACKEND_MT5` вместо ложного успешного результата.
