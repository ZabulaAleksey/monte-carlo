# Порядок запуска исторических этапов

Этот сохранённый порядок не является второй копией требований. Каноническое
содержание этапов находится в [дорожной карте](../MONTE_CARLO_ROADMAP_13_TO_28.md).

Перед запуском этапа:

1. прочитай соответствующий раздел дорожной карты;
2. проверь selected record в [`docs/STAGES.md`](../STAGES.md), зависимости и технический долг;
3. подготовь ограниченный SPEC/ADR и план проверок;
4. реализуй только явно запрошенный этап;
5. обнови живой контекст и остановись перед следующим этапом.

Этапы 14–28 опциональны; historical launcher в `docs/STAGES.md` не даёт
разрешения запускать их без отдельного решения пользователя.
