# Журнал технических решений

Документ фиксирует только решения, влияющие на архитектуру или эксплуатацию проекта.

## 2026-08-13 — Изолировать tracing root frontend-приложения

- **Решение:** для Next.js standalone-сборки явно задать `outputFileTracingRoot` равным каталогу `apps/frontend`.
- **Причина:** автоматическое определение корня поднималось до `~/codex-workspace` из-за внешнего `package-lock.json`. В результате `server.js` оказывался внутри пути репозитория, а Docker-образ ожидал его в `/app/server.js`. После переименования каталога в артефакте также сохранялся старый сегмент `MonteCarloStrategy`.
- **Альтернативы:** удалить внешний lockfile; изменить Dockerfile под динамический вложенный путь; использовать корень всего репозитория. Эти варианты либо затрагивают чужую рабочую область, либо снова связывают образ с именем каталога.
- **Последствия:** standalone-артефакт не зависит от расположения и имени репозитория; зависимости вне `apps/frontend` не попадут в trace без отдельного осознанного изменения конфигурации.
